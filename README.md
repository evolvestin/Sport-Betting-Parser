# Sport-Betting-Parser

## Описание проекта
**Sport-Betting-Parser** — это комплексное программное решение на языке Python, предназначенное для автоматизированного сбора (парсинга), анализа и публикации спортивных прогнозов и результатов матчей. Система работала в режиме реального времени, отслеживая изменения коэффициентов, ход матчей и статистические показатели.

Архитектура приложения построена на взаимодействии нескольких потоков: сбора данных через веб-драйвер, управления локальной базой данных SQLite, синхронизации с облачными сервисами Google и интерфейса взаимодействия через Telegram-бота.

## Основной функционал
1.  **Web Scraping (Парсинг):**
    *   Использование **Selenium WebDriver** для эмуляции действий пользователя и обхода защиты веб-ресурсов.
    *   Мониторинг линий ставок, включая исходы (П1, П2, Х), двойные шансы (1Х, Х2) и вероятности событий.
    *   Сбор данных о текущем счёте матчей и времени игры.

2.  **Работа с данными (SQLite):**
    *   Сохранение всех событий в локальную реляционную базу данных.
    *   Отслеживание динамики изменения коэффициентов (Live-режим).
    *   Автоматическое определение статуса ставки (Выигрыш/Проигрыш/Возврат) на основе итогового счета.

3.  **Интеграция с Google Sheets:**
    *   Экспорт собранной статистики в Google Таблицы через API (`gspread`).
    *   Структурирование данных для последующего аналитического разбора.

4.  **Telegram Bot:**
    *   Автоматическая публикация прогнозов в канал.
    *   **Live-обновление сообщений:** изменение текущего счета и статуса матча непосредственно в теле поста (edit_message).
    *   Уведомления о завершении событий и результатах ставок.

## Технологический стек
*   **Язык программирования:** Python 3
*   **Браузерная автоматизация:** Selenium (Chrome WebDriver)
*   **База данных:** SQLite3
*   **API и библиотеки:**
    *   `pyTelegramBotAPI` (TeleBot)
    *   `gspread` (Google Sheets API)
    *   `requests`
